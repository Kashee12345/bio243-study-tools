# BIOL 243 Study Tools

Interactive walkthroughs and games for BIOL 243 Human Anatomy & Physiology, by Dr. Akash Garg.

**Live site:** https://kashee12345.github.io/bio243-study-tools/

## What's here (5 resources)

**Muscle contraction**
- `Contraction-Walkthrough.html`: animated, step-by-step walkthrough of the neuromuscular junction, excitation–contraction coupling, the cross-bridge cycle and relaxation, with a quick check at each step
- `Contraction-Chain-Game.html`: sequence-sorting game plus "What breaks if…?" scenarios
- `Muscle-Contraction-Without-the-Panic.pdf`: printable plain-language study guide with practice questions and answer key

**Bone formation and fracture healing**
- `Bone-Formation-Walkthrough.html`: animated walkthrough of intramembranous ossification, endochondral ossification, the epiphyseal plate and fracture healing
- `Bone-Builder-Game.html`: ordering, classifying and name-that-stage games

Every page is a single self-contained HTML file. No login, no tracking, no student data. Progress in the games is kept only in the student's own browser.
